
# Project Title

    AIUB BUS MANAGEMENT SERVICE



## Introduction
    The AIUB Bus Management System is a digital platform that automates university transportation management. It includes Admin, Student, and Driver panels for managing routes, schedules, payments, and pickups. The system improves efficiency, reduces manual errors, and ensures reliable transit services.
## Features and Facilities
    Centralized admin dashboard for managing buses, routes, students, and payments.
    Dynamic route and pickup point management.
    Student self-service for route, schedule, and pickup selection.
    Online fee payment and due tracking system.
    Real-time driver schedule and route updates.
    Pickup confirmation with live student count tracking.
    Secure login and profile management for all users.

## Functionalities
    1. Authentication & Security
    Secure login system for Admin, Student, and Driver.
    Student registration with academic information.
    Real-time database synchronization and account validation.
    2. Admin Panel
    Dashboard for monitoring revenue and transactions.
    Route and pickup point management.
    Student account management (Active/Block).
    Driver and bus assignment management.
    3. Student Panel
    Route, schedule, and pickup point selection.
    Online fee payment and transaction history.
    Profile and academic information management.
    4. Driver Panel
    Daily schedule and assigned route tracking.
    Live student count for each pickup point.
    Boarding confirmation with real-time admin updates.

## Tech Stack
    * Language & Framework: C# with .NET Windows Forms
    * Architecture: OOP and N-Tier Architecture
    * Database: Microsoft SQL Server using ADO.NET and T-SQL
    * Development Tools: Visual Studio and SQL Server Management Studio (SSMS)
    * Key Features: Role-based authentication, real-time data updates, and dynamic reporting using GridViews/DataTables
## How toRun

    1. Download or clone the project source code.
    2. Create a database in SQL Server and run the provided SQL script file.
    3. Open the project .sln file in Visual Studio.
    4. Update the SQL Server connection string if needed.
    5. Build and run the project from Visual Studio.
